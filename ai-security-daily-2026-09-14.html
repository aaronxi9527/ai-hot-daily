AI 总览 · 今日看点

今天最值得盯的一件事：国内智能体安全开始「平台化落地」，而不是停留在概念层。启云方在 AI 生产力大会上正式发布启云方舟 2.0，并端出「小笼虾」智能体安全方案——身份网关、AI/模型网关、作业网关三层 + 六层围栏，直接给出「影子 AI 发现 → 交互审计 → 精细权限」的完整闭环；同一天网安周体验区里，中国移动端出 37 项网信安全智能体与「智能体安全监管平台」（已对 280 项大模型、699 项智能体做完风险排查），中国电信的星辰超级智能体 TeleAgent 也把四层安全防护做进产品并过了信通院类 Claw 检验。三家不约而同把「智能体准入 + 运行时拦截 + 事后追溯」写进产品，说明国内这一轮是真在卖东西了。

国际侧的动作集中在同一个技术点：把策略执行点从「事后审计」前移到「动作发生之前」。Nightfall AI 的 MCP Gateway、开源的 MCPbouncer 都明确要在工具调用执行前拦截、修剪高危操作、代理凭据；Google Cloud 把 VPC Service Controls 铺到 Agent Gateway，并让 Agent Runtime 与 Agent Identity 转正 GA——补的正是智能体架构评审里最常缺的那块网络边界。Cloudflare 则把 CASB 做成自动撤销高风险共享的自动化引擎。一个行业数据很能说明紧迫性：91% 的组织只能在智能体做完之后才发现它做了什么，仅 23% 有内联实时执行能力。

监管与事件层面，今天是「网安周开幕日 + 标准密集落地」：2026 国家网络安全宣传周在济南开幕，《人工智能安全治理框架》3.0 版本周发布，9 月 15 日人工智能安全治理分论坛、9 月 16 日开源供应链闭门会排上日程；国内首个金融智能体安全团标落地，把「用户 + 机构双重授权」写成硬底线，读屏模拟类智能体面临改造压力。风险侧也不安静——Anthropic 第四份威胁报告披露三大 GTG 集群（含疑似长沙运营者用自主 Agent 一个月挖出十余个潜在零日）；LiteLLM 公网暴露扫描显示近 10% 实例还在用默认主密钥 sk-1234。

CISA / LiteLLM漏洞披露 / 在野利用
🔥🔥🔥重大

LiteLLM AI 网关暴露面扫描：近 10% 公网实例接受默认主密钥，CVE-2026-59822 已被在野利用

研究者对 3,074 个可公开访问的 LiteLLM AI 网关实例进行扫描，发现 294 个系统（9.6%）接受广为人知的默认主密钥 sk-1234，191 个实例（6.2%）完全未启用身份认证。最严重的外部可访问问题为 CVE-2026-59822，影响 LiteLLM 的 MCP 流式 HTTP 端点：在 1.84.0 之前，攻击者可提供任意 Bearer 令牌触发 OAuth2 回退路径，把失败的 API Key 校验转化为一个空的已验证用户对象——即使只有一个字符的令牌也能建立有效 MCP 会话并访问已配置的 MCP 工具。由于 MCP 服务器不仅暴露数据还暴露操作，被攻破的网关可能连带提供对内部数据库、源代码库、工单系统、Slack 工作区、文件存储、CI/CD 工具的访问。研究者还演示了利用直通端点（pass-through）配置指向云元数据服务（169.254.169.254）窃取临时 IAM 凭据的场景。该漏洞已被列入 CISA 已知已利用漏洞目录。缓解建议：升级至 1.84.0 以上、更换强主密钥、限制 MCP 访问并审计配置。

Claude Code CVE-2026-21852 审计：pre-trust 执行窗口可致 API Key 窃取与 Hook 劫持

一项针对 Claude Code CVE-2026-21852（CVSS 5.3）的安全审计披露：在 2.0.65 之前的版本中，CLI 会在评估目录信任之前就把 ./.claude/settings.json 合并进运行时上下文。攻击者可在开源仓库中提交恶意的 .claude/settings.json，通过 env 段把 ANTHROPIC_BASE_URL 重定向到受控域名并开启 allowBash；开发者克隆仓库后运行 claude，运行时立即发起的模型列表/配额校验请求会由 Anthropic SDK 自动携带 x-api-key 头直发攻击者服务器，明文收割有效凭据。同一 pre-trust 窗口还延伸到生命周期 Hook（SessionStart 中的 curl | python3 立即执行）与 git 元数据劫持（CVE-2025-59536，在 .git/config 中配置 core.fsmonitor 反弹 shell，任何 git status/git diff 都会触发）。审计还指出 Linux 环境下会话令牌与 MCP 凭据曾以明文存放于 ~/.claude/.credentials.json。
