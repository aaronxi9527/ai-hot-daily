PraisonAI（开源框架）

PraisonAI CodeAgent 曝 CVE-2026-61447 严重 RCE 漏洞（CVSS 10.0）

漏洞披露AI Agent 框架

7/11 公开披露 PraisonAI AI Agent 框架中 CVE-2026-61447 严重 RCE 漏洞，影响 1.6.78 之前所有版本，CVSS 评分 10.0（v3.1 / v4.0 双满）。CodeAgent._execute_python() 直接执行 LLM 生成的 Python 代码，无 AST 校验、无 import 限制、无沙箱强制——攻击者通过提示词注入即可让 Agent 在主机上运行任意代码，窃取 API key、云凭证、数据库密码等环境密钥。PraisonAI 1.6.78 已修复，建议立即升级并轮换潜在泄露密钥。
