AI 总览

今天最值得记住的一条是行业标准开始由厂商自己写：Google、OpenAI、Anthropic 正联手筹建 SAFA「前沿人工智能标准管理局」，目标年底或 2027 年初启动——因为原计划「行业自律 + 政府监督」在特朗普政府内部受阻、国会中期选举前又难成 AI 立法，三家索性转向独立于政府运作，把第三方部署前测试、事件报告规则、自愿承诺转化为执行标准、审计机构资格认定这四件事自己定下来。与之配套的另一条暗线是「管智能体做错事」成为共识：奇安信齐向东说「智能体自主攻击已经发生，要划红线设笼子」，而产品侧同一天就有 Abnormal AI 把「AI Agent Security」做进套件、SentinelOne 把狩猎推到云控制面、Gurucul 的检测覆盖全部 16 个 MITRE ATLAS 战术、PANW 把模型扫描做成可被其他 Agent 调用的 A2A Agent。第二个主线是攻击面继续从模型搬到管道：ServiceNow AI Platform 两个授权绕过（最高 CVSS 9.3）与 Langflow CVE-2026-9198 未认证 RCE（CVSS 9.8，已进 CISA KEV）的触发条件都是出厂默认配置——前者是管理平台授权缺失，后者是 auto_login 默认开着、代码直接进 exec() 无沙箱；同时 MemTensor 的 npm/PyPI 恶意包把窃取点设在「记忆召回」和「日志 hook」这种最不容易被察觉的位置。产品侧还有一条清流：SecEdge 给模型发密码学「护照」，把模型来源与完整性验证做成可流转、可离线校验的凭证。资本层面，Island 以 64 亿美元估值完成 4 亿美元 F 轮，Gartner 则把「securing AI」认定为唯一在 2030 年前持续加速的安全品类、2029 年将成企业安全最大单项支出。一句话：标准在被厂商抢先写，攻击在被默认配置养大，而钱正在从传统安全重新分配到 AI 安全。

PANW Prisma AIRS 接入 Google Cloud Agent Gateway，模型扫描 Agent 上架云市场

9 月 24 日，Palo Alto Networks 披露其 Prisma AIRS 运行时安全与 Google Cloud Agent Gateway（Gemini Enterprise Agent Platform 组件）的集成：通过在网关上添加一个 service extension，即可把全部 MCP 工具调用与响应送往 Prisma AIRS API 检查，官方称秋季将进一步扩展到扫描 Gemini Enterprise Agent Platform 智能体的全部用户输入与输出。产品负责人 Spencer Thellmann 强调 MCP 连接是双向暴露——敏感凭据可能随智能体请求外泄，被攻陷的 MCP 服务器也可能在工具描述里返回恶意链接、恶意软件或间接提示注入，「今天合法的服务器，明天可能就不合法了」。另一条动作是把模型扫描服务打包成 Agent 上架 Google Cloud Marketplace：基于 A2A card 构建，其他智能体可直接与它对话——如果某个智能体负责从互联网拉取模型并送进推理服务，它可以先把模型送去扫描 Agent 取回策略裁决，再继续工作流，把安全从事后人工审查变成机器对机器的自动化环节。Thellmann 的核心判断是「不能把智能体当聊天机器人对待：自主性、记忆与工具调用让它们强大，也让它们危险」。

Google / OpenAI / Anthropic行业标准 / 自律机构🔥🔥🔥合并 4 源

三家 AI 巨头联手筹建 SAFA「前沿人工智能标准管理局」，转为独立于政府运作

9 月 24 日 The Information 报道，Google、OpenAI、Anthropic 正自行推进成立 AI 安全标准机构，暂定名「前沿人工智能标准管理局」（Standards Authority for Frontier AI，SAFA），目标今年年底或 2027 年初启动。路线出现关键转向：三家公司最初希望建立「行业主导 + 接受联邦监督」的公私合作机制（参考美国金融业监管局 FINRA 模式），但方案在特朗普政府内部推进受阻，加上国会在中期选举前难以形成新的 AI 立法，转而准备先以行业自律方式填补监管空档、独立于政府运作。核心职能不是一般性伦理原则，而是可执行标准：支持第三方机构在模型正式部署前开展安全测试；制定 AI 企业发生安全与安保事件后的报告规则；把三家此前的自愿安全承诺转化为具体执行标准；设定独立审计机构需要满足的资格要求。工作组还在讨论 SAFA 是否亲自开展模型安全与能力测试——目前这类测试由美国商务部人工智能标准与创新中心（CAISI）承担，部分成员担心其资源不足。此外据报道，OpenAI 与 Anthropic 还在商谈交叉测试协议，允许双方对彼此的商用模型做压力测试以查找漏洞与意外行为，但评估中获得的数据不得由测试方保留，以保护专有模型。白宫此前曾提出，在政府正式参与前几家公司需先争取更广泛的行业共识。

🧭趋势判断精简版

基于今日 23 条动态的归纳，供快速判断用

1. 标准制定权正在从政府转向厂商。SAFA 的路线转向（放弃公私合作、转为独立自律）说明在缺乏立法的情况下，前沿实验室选择自己定义测试、审计与事件报告规则。对企业采购的影响是：未来评估供应商时，「符合 SAFA 标准」可能先于「符合某国监管」出现。

2. 管理平台与默认配置成为最高杠杆的攻击点。ServiceNow AI Platform（CVSS 9.3）、Langflow（CVSS 9.8，已在 KEV）的共同点是「默认开着、权限过大、无沙箱」。安全团队本周最该做的两件事：盘一遍所有 AI 相关组件的出厂默认开关，以及把所有集中管理面按「打掉一个等于打掉全部」来定优先级。

3. 智能体治理的产品形态收敛到三种。①执行路径上的网关（PANW 的 service extension、Okta 的 Agent Gateway）；②身份与权限的运行时裁决（Abnormal、Gurucul、Island 的控制平面）；③检测层的战术全覆盖（MITRE ATLAS 16/16）。三者互补，短期内不会互相取代。

4. 模型供应链安全开始有产品级答案。SecEdge AI-PASSPORT 把「这个模型是不是被批准的那个版本」变成可离线校验的密码学凭证，直接回应开源权重模型被投毒、仿冒重分发的现实风险。这是本周唯一从根上处理「模型本身可信」的产品。
