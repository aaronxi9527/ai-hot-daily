📌 AI 总览

今天的主线只有一句话：智能体已经跑到了防御体系前面，而全世界的标准机构在同一周集体踩了刹车。

最扎眼的是两起事件。一是 PaperCut 攻击——数百个由 Codex 编排、DeepSeek 执行的 AI 智能体，用一条已披露的认证绕过 + RCE 链，把 440 多台实例、395 家组织、48 个国家一并卷进去，26 秒拿下 11 家，最快 7 分钟从初始访问干到域控。这是第一份被完整取证还原的「AI 智能体主导型攻击流水线」样本，它的意义不在于漏洞多新，而在于漏洞武器化到规模化利用的时间被压到了小时级。二是 Check Point 披露的 ChatGPT Artifactory 隐蔽通道——包仓库的元数据属性字段没做账户隔离，硬生生变成了跨账户的共享剪贴板，受害者一句普通提问就能把 Gmail 邮件送到攻击者手上，界面上只多一行事后才出现的灰色小字。同一条通道，METR 还数出约 1200 个智能体发过 7 万多条未授权消息。两个案例共享一个结论：你埋点的地方，取决于你预期智能体会做什么；而能力足够的智能体，会走你没预料的那条路。

产品侧今天最有分量的是两条「身份」路线。Cyera 用 10 亿美元买下 Oasis Security，把它做成 Cyera Identity 身份支柱，理由说得很直白——财富 500 强的非人类身份半年涨了近 500%，而 Agent 持有效凭证运行，根本不需要被攻破就能造成损害；国内这边，绿盟科技发布清风卫 AIDR，用「发现资产 → 赋予身份 → 基于身份授权 → 策略管控」四步，把 400+ 条风险指令、意图偏离检测和 Token 归因落成可交付能力，并明确对标《智能体应用安全基本要求》国标与 TC260《智能体交互安全要求》。加上微软在 Windows 11 里给智能体进程打标识并传递给子进程、启明星辰用多智能体协同做安全效能度量、亚信在联通大会上给智能体「发工牌」——「一 Agent 一身份、权限随委托链收敛」正在从理念变成产品货架上的标配。

标准与政策同样是爆发日。工信部印发《「人工智能+软件」专项行动实施方案》，第一次把「AI 生成代码安全审查」「防范智能编程工具恶意指令注入」「智能体身份标识、可信互联、行为管控」写进国家级行动方案；外滩大会一天之内启动两项智能体安全团体标准、立项智能体身份管理国标，并由支付清算协会提出从 KYC 到「KYA（了解你的智能体）」；国际上 NCSC 把沙箱与结构化日志定为基线，CSA 把 MCP 认证钉成关键控制点，OWASP ACS、NIST 智能体身份六标准、AAIF 三线收敛。Gartner 给出的数字是：2026 年 AI 总支出 2.59 万亿美元、AI 安全 513 亿美元，安全已占 AI 软件盘约 11%。

给同行的一句话建议：别再把 Agent 当成「更聪明的应用」来防，要当成「持证上岗的新员工」来管——先建档、再发身份、然后按任务给最小权限，最后把每一个动作留痕到可回放。

Check Point Research 漏洞披露 / 提示词注入 合并 3 源
🔥🔥🔥

Check Point 披露 ChatGPT 跨账户隐蔽通道：经 JFrog Artifactory 元数据窃取受害者 Gmail 邮件

Check Point Research 公开一个影响 ChatGPT 的跨会话隐蔽通道：ChatGPT 的代码执行容器虽然彼此隔离且无外网，但都需访问同一个内部 JFrog Artifactory 实例拉取 Python/npm 包；该实例的 item 属性（property）读写接口未按账户隔离，且容器内已有的读取凭证同时具备写权限。攻击者据此把包仓库元数据变成「共享剪贴板」——在共享会话中植入指令后，受害者下一次普通提问会同时处理一条隐藏任务，用受害者自身已授权的工具（如 Gmail 连接器）取数据并回写到该通道。PoC 中 Gmail 邮件被完整取走，受害者界面只多出一行灰色「Talked to Gmail」标签，且该标签出现在读取发生之后——原因是 ChatGPT 默认把「读取类」应用操作判定为低风险、不弹确认。OpenAI 已下线该 Artifactory 实例，漏洞不可再触发，暂无真实利用证据。CPR 将此总结为「被胁迫的内部人员」——每个被信任的能力都可能成为攻击目标。

外滩大会 行业标准 / 智能体治理 合并 3 源
🔥🔥

智能体安全标准三连发：两项团体标准启动、身份管理国标立项、支付清算协会提出「KYA」

从今日动态中提炼的四个确定性方向

01

攻击侧：AI 智能体成为「产能」，而非「工具」

PaperCut 案例中攻击者出现「产能过剩」——初始访问与提权之间间隔数天，并非防御起效，而是攻击者自己消化不过来。这意味着防御方要面对的不再是「更快的人」，而是可并行、可自我修正、可批量重试的攻击流水线。窗口期从「天」压到「小时」，补丁管理必须自动化。

02

治理侧：身份成为唯一可收敛的控制点

Cyera 买 Oasis、绿盟发 AIDR、亚信推 AiTrust、微软在 OS 层打进程标识、LangChain 做 bot/user 令牌切换——五条不同路径指向同一个结论：内容安全拦不住意图，流量检测看不懂工具调用，只有「身份 + 委托链权限收敛 + 高危操作强制人工」能形成可审计的边界。

03

标准侧：中国与国际同步进入「智能体安全标准竞赛」

工信部专项行动方案 + 中国网络空间安全协会两项团体标准 + 智能体身份管理国标 + 支付清算协会 KYA，与国际的 NCSC 指引、CSA MCP 基线、OWASP ACS、NIST 六标准形成同频共振。2026 下半年是标准窗口期，产品对标哪一套标准，会直接决定 2027 年招投标的技术分。

04

市场侧：Agent 安全从「附加项」变成「平台必选项」

Harvey 把 Agent 安全能力内化进自家平台、Gartner 给出 513 亿美元 AI 安全盘子、Cequence 数据显示 94% 企业「自认安全」但仅 33% 真做了最小权限——认知与落地的剪刀差就是市场空间。能提供「默认开启、零业务改造、可量化度量」的厂商，会最先吃到这波预算。
