结构性判断：AI 安全的重心已经从「模型说了什么」整体前移到「agent 能做什么」。身份权限 42、智能体安全 37、MCP 安全 27，三者合计 106 / 147 = 72.1%；而被视为 AI 安全代名词的提示词注入只有 10 条（6.8%）、LLM 网关/WAF 9 条（6.1%）、AI-SPM 仅 2 条（1.4%）。这个比例不是媒体偏好造成的——同一周内 NIST 把 agent 身份管理单独立项（十条原则、600+ 份公开意见）、微软发布 agent 依赖锁文件的包管理器、Teleport 用 Control Identity 替代逐步审批，三条互不相关的动作指向同一个结论：护栏装在模型出口已经没有意义，闸门必须装在 agent 的身份与工具调用边界上。对做边界设备的厂商，这是个好消息——那道闸门的位置，恰好是网关与防火墙的传统射程。

04对 NF 的判断

判断与事实分开；每条标注证据强度

01
AI 安全的闸门位置正在向网关与边界设备迁移，这是 NF 的能力射程。身份权限 42、智能体安全 37、MCP 安全 27 合计占品类标签的 72.1%，而传统护栏类（提示词注入 10 + LLM 网关 9 + AI-SPM 2）仅占 14.3%。NIST 把 agent 身份单独立项并明确「判定必须落在模型外面」，Teleport 用 Control Identity 替代逐步审批，Sysdig 靠内核侧对账不信任 agent 自报日志——三条独立动作指向同一件事：可信边界在 agent 与外部系统之间，不在模型内部。而那个位置的历史占有者，是防火墙。
证据强 品类分布来自 147 个标签统计；方法论共识来自 3 个独立信源
02
「MCP 网关」可以作为一个独立产品位来卖，不是一个功能点。本期 MCP 相关漏洞密度异常：官方参考实现一次被报 7 个 CVE（标注「只读」的 git 工具也能执行代码）、AWS API MCP Server 被大写字母绕过策略、Mendix MCP Server 把 7782 端口直接开给全网、mcp-gateway-registry 的 SSRF、9,720 格矩阵测出 22.9% 打穿且12 个框架无一实现工具投毒防御。同时腾讯云 AI 网关 3.9.8 已把 MCP 网关的 OAuth 2.0 授权码做成正式能力。供给侧有真需求、有标准答案（OAuth 2.1 + 零 token 透传，如 Byward v0.1.0），但开源侧几乎无人做对。
证据强 5 个独立 CVE + 1 篇量化测量 + 1 个厂商 GA
03
国家级认证已成标书门槛，安恒已抢先拿证，窗口正在关闭。同周三条认证线全部落地：公安部三所「大模型安全防护围栏（增强级）」证书（安恒 MAF 首获，且是「型式试验 + 获证后监督」，拿证后持续受监督）、信通院政务领域智能体安全测评首批（腾讯 WorkBuddy 企业版最高等级，六大原则 + 三大安全等级）、网信办四类备案合一（生成式 AI／算法／深度合成／区块链同入口，旧系统同步停用）。这三条都不是「加分项」，而是投标资格项。NF 侧若要在 AI 相关标里出现，须提前把这些证书与测评材料作为标书前置清单固定。
证据强 时间敏感：安恒已拿证，后进入者需要 1–2 个测评周期
04
「运行时可信」的方法论已收敛成四条可落地的设计原则，可直接映射为产品需求。① 不信自报——Sysdig 内核侧与 harness 侧双侧对账，agent 说它调了什么不算数；② 看执行计划而非逐步审批——Teleport Beams 的 Control Identity，一步一审批在生产里不可行；③ 依赖要锁——微软 apm 用 apm.yml 加提交级锁文件，Dependabot 给 agent 技能提 PR；④ 策略要可验证——NVIDIA OpenShell 改用 Cedar 并做形式化验证。这四条恰好是「设备厂商能提供、SaaS 厂商提供不了」的部分：本地执行点、本地策略校验、不依赖云端日志。
证据中等偏强 四条原则各有独立信源，但尚无厂商把它们打包成一个产品
05
国内仍是产品真空期，但资本与认证两条线同时在动，别把「没发布」当成「没动作」。本期国内具名体系发布只有亚信 3+1 一条（AIBOM / AIIAM / AIASP + ATF + AI 安全网关，兼容 SPDX 3.0），奇安信、安恒的论坛发言因无版本变更被剔除。但同期：深信服、启明星辰、绿盟 Q3 收入全部转正；绿盟清风卫入选 IDC 企业级智能体安全报告、天融信入选 IDC 智算中心安全报告；安恒拿公安部三所证书。「看不见、管不住、查不清」是亚信给的市场诊断，也是这一轮产品空窗期里所有厂商共同的起跑姿势——真正要盯的是谁先把 AIBOM 这类资产侧能力做进既有设备，而不是谁的发布会开得早。
证据中等 单周窗口 + 中文检索口径，可能有遗漏未公开的产品动作
本期不建议采信的两类信息：① 一切「检出率 / 拦截率」百分数——本期出现的 95%、47%、22.9% 分属三种不同口径（厂商宣称、特定基准 OPI、自建 9,720 格矩阵），互相不可比，引用时必须带口径；② 「白底白字」类注入案例的法律效力——巴西第八地区劳动法院对两名律师罚 1.6 万美元（涉案金额 10%）确实发生了，但注入本身没有成功，判罚理由是「有损司法尊严」，不宜作为「注入可被追责」的判例引用。
