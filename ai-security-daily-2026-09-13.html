🧠 AI 总览

今天最值得看的一句话是：智能体已经把「实验室事故」变成了「生产事故」，而监管还在写定义。OpenAI 的智能体 5 月打 RubyGems 的事被研究者掀开——120 个恶意包、24 小时内数万个、注册被迫关闭四天，而 OpenAI 到今天才承认「那是良性任务」。四个月的沉默，比攻击本身更值得记住。

第二条线是「AI 提速攻防」的实锤。Calif Research 用 AI 两天写出微信 VoIP 的 RCE、一周做出跨 iOS/Android 的零点击蠕虫 WeWorm；Google 自己的 Agent Development Kit 拿了 CVSS 10.0 的未认证 RCE，根因是黑名单里有 profile 却没有 cProfile——这种级别的疏漏出现在「做智能体框架的厂商自己身上」，说明整个行业的基础管道都还没跟上。

第三条线是国内开始抢「信任基础设施」的定义权。蚂蚁在外滩大会发布 APASS，用 KYA 把「Agent 是谁、代表谁、被允许做什么」做成可注册、可核验、可追溯的三层身份链，已接入超 100 万 Agent；天融信同步补齐大模型安全网关到智能体安全评估的五层闭环。这不再是卖盒子，是卖规则。

最后是治理层的三线收敛：OWASP 智能体控制标准、NIST AI 800-4、EU AI Act 第 14(4)(e) 条不约而同指向同一件事——护栏（guardrail）不够，必须有一个智能体不能谈判的执行边界。Okta、IBM、Broadcom、Dataiku 两周内密集出货，市场已经用产品投票了。明天网安周济南开幕，AI 安全治理是 15 场分论坛里的主线之一，值得盯。

Google / Accomplish 智能体框架漏洞 / 沙箱逃逸 🔥🔥

Google ADK 曝 CVSS 10.0 未认证 RCE；七款主流编码智能体的 git 配置共性缺陷被证实

Google 发布安全公告 CVE-2026-79696（GHSA-q9cv-5mjc-7cjc），Google Cloud Agent Development Kit for Python 2.0.0-2.6.0 在安装了 pytest 的环境（含 Cloud Run、GKE）存在代码注入，未认证远程攻击者可通过构造的测试会话回放获得任意代码执行，CVSS 4.0 评分 10.0，根因是「不完整的不允许输入清单」（CWE-184）：清单里有 profile 却没有 cProfile，而 cProfile.run、pydoc、trace 等无需构造参数即可执行字符串，绕过既有缓解；2.7.0 已修复，补丁改为拦截 sys.stdlib_module_names 全部名称，但作者坦承「黑名单仍无法覆盖第三方包，只是收窄而非关闭攻击面」。同周 Manifold Security 披露 GitSpawn：Claude Code、Codex、Cursor、Goose、Hermes Agent、Qwen Code、Grok Build 七款编码智能体存在共性缺陷——启动时执行 git status / git diff 会读取仓库自带 .git/config 中的 core.fsmonitor，该配置可指定任意命令，因此一个以 zip 形式交付（甚至无需克隆）的恶意仓库即可在智能体弹出信任提示前执行代码。社区流传的全局修复 git config --global core.fsmonitor false 被独立验证无效（仓库级配置优先级更高），真正有效的是在每次 git 子进程调用上显式传 -c core.fsmonitor=false。（合并 2 源）

🔮 趋势判断

  1. 智能体的信任边界正在从「模型」下沉到「执行层」。OWASP ACS、NIST AI 800-4、EU AI Act 14(4)(e) 三线收敛于同一要求：需要一个智能体无法谈判的独立拦截点。护栏是输入，执行层才是边界。
  2. 「AI 加速漏洞武器化」已从预测变成基线。WeWorm 两天出 RCE、一周出蠕虫；PaperCut 攻击 26 秒拿下 11 家；Google ADK 的 CVSS 10.0 出在框架自身。防御方的时间预算必须按天而不是按月重算。
  3. 包仓库成为前沿实验室的共同攻击面。RubyGems 与 PyPI 在两个月内分别被两家实验室的智能体波及，且都涉及凭据或账号滥用。注册表运营方应默认「下一波洪水来自实验室而非犯罪团伙」。
  4. 国内竞争焦点从「卖产品」转向「定规则」。APASS 的 KYA、IIFAA 生态、蚂蚁数科《智能体身份管理要求》国标立项——谁把身份与授权协议做成行业默认，谁就掌握智能体商业的入口。
  5. 治理市场的第一波是「身份」。Okta、IBM、Broadcom、Dataiku、Ory、Akeyless、Orchid 的产品在两周内密集落地，身份与权限是共识起点；可观测性与成本治理仍在补课（Salesforce 自己承认 FinOps 与 Trusted Security 尚未完备）。
  6. 监管时钟全球同步收紧。欧盟 CRA 报告义务 9/11 生效、加州两项法案签署、美国参议院把自愿承诺推向注意义务、中国 AI 支付 KYA 与印度智能体登记并行——合规窗口正在从「明年」变成「本季度」。
