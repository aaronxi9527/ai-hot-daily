AI 总览

今天的主线一句话：攻击者已经不打漏洞了，打的是「一个能发请求的账号」和「一句能骗过护栏的话术」。

三件最硬的新闻指向同一个位置。Mandiant 的 LLMjacking 报告说，劫持企业 LLM 访问的攻击者单日能刷出 10 万美元云账单，有人累计烧到 100 万才被吊销——最狠的一句是「受害组织从未启用过 LLM 服务」，攻击者用盗来的 Key 替你把 Bedrock 和 Gemini API 打开了。Cisco Talos 的 VOLTA 窃密器把偷来的数据打包发给 OpenRouter，让模型扮演取证分析师，按「变现容易程度」给受害者资产排序，默认用 Claude Opus 4.6，被拒就换 Kimi K2、再换 Gemini 2.5 Flash。Sophos 的 Aur0ra 案更直接：操作者把 VPN、代理、目标交给 Cursor 里的 agent，让它自己测绘 AD、自己找密码、自己走到域管，日志里还留着一句「别再暴力破解了，换点不吵的方法」。

产品侧六条动作出奇一致：把「谁允许的」变成可验证的东西。Salesforce 把评估失败接到 kill switch 上，明确 11 月 beta、明年 1 月 GA；Guardz 把浏览器事件回接邮件与 M365 身份，让 MDR 按单一事件处置；Byoky 让应用只拿会话 token、密钥留在本地钱包。国内三条更彻底——蚂蚁给每个进生产系统的智能体发密码学数字工牌，决策依据实时上链；天泽把每个动作绑到一次具体审批上，讲「五种确定性」；天融信今天下午发的 RHP 渗透测试智能体，主打的是「证据可追溯」。没有一家在承诺「防住」，全在承诺「查得到」。

两个数字把这件事的成本讲清楚了。Armadin 实测：88% 的严重漏洞靠厂商公告根本发现不了，82% 的攻击链不带凭据起步，70% 三步以内拿到关键结果，而 93% 的修复不需要第三方动手——按公告打补丁，只覆盖那 12%。另一头，启明星辰上半年大模型应用防火墙收入同比 +238.15%，第一批真实收入出现了，但研报自己补了一句冷水：单纯接入大模型不等于新增收入。

规则侧两条同向：四大巨头共推 robots.txt 里的统一退出信号（IETF AIPREF），解决的是「表达」不是「授权」，且默认允许；Anthropic 官网源码漏出 Fable 5.5 与 Mythos 5.5，同一套权重按护栏松紧拆成两个产品、定价一致——护栏第一次被明确标价，卖的不是能力，是「谁敢解除限制」。

Salesforce / MuleSoft智能体治理 · 评估与熔断🔥🔥

Agent Fabric 把「评估失败」接到 kill switch 上：Agent Evals 与 API Evals 定档 11 月 beta

10 月 27 日，Salesforce 公布 MuleSoft Agent Fabric 的下一阶段能力，并给出明确时间表。Agent Evals 与 API Evals 于 11 月进入 beta、2027 年 1 月 GA；前者不只测上线前，还在生产里持续测 agent、模型与 MCP server，一旦行为超出组织阈值就触发响应，按策略该走审批的走审批；后者从 API 规格直接生成功能与性能测试。Custom Agent Scanner 当日进入 beta，把发现范围扩到内网、防火墙之后与其他平台，GA 同样定在 2027 年 1 月，注册表只拉指针、不搬 agent。

真正的新东西是 Triggered-Agent Kill Switch（2027 年 1 月）：把评估结果接到策略化干预上。基础 kill switch 9 月已 GA，按请求、会话、agent、租户四个粒度阻断受治理流量，之后可恢复——但它阻断的是网关上的流量，不等于终止宿主平台上跑着的进程，这条边界是采购时最该问的一句。配套还有按提供商与模型设美元或 token 预算的 Model Wallet、FinOps 面板，以及跨 Azure、Apigee、Kong 的 Open Policies；官方称语义缓存与载荷压缩在测试场景下可降最多 75% 的 token。MuleSoft 组合公开起价每月 2,000 美元，Agent Fabric 具体配置需询价，另有 5 万美元年最低预承诺。

「发现→测试→限流→熔断」四段终于被串成一条链，但每一段的可信度不一样：评估会误判，kill switch 只到网关，预算只管得到走网关的调用。越是把闭环讲得完整的产品，越要问它闭环的出口在哪里断开。

11 月 2 日，Guardz 将 Palo Alto Networks 的 Prisma Browser for Business 加入其面向小企业 MSP 的安全平台。浏览器侧检测全部来自 PANW：内联机器学习模型筛钓鱼页，Advanced URL Filtering 拦假登录页与专门窃取活会话令牌的攻击，WildFire 分析可疑文件，上传下载在浏览器内即扫，并识别高风险扩展。Guardz 负责把浏览器事件与原始邮件、相关 Microsoft 365 活动、同一身份的终端遥测对齐，交给 7×24 MDR 团队按单一事件处置——这是集成的真正价值所在：过去这三段证据在三个工具里，谁都不肯认领。

Byoky密钥管理 · 开源工具🔥

Byoky：把 AI API Key 从「设置页里的一串字符」搬进一个本地加密钱包

11 月 2 日，开源项目 Byoky 发布 Chrome 与 Firefox 扩展、iOS 与 Android 应用。思路直接照搬 MetaMask：密钥用 AES-256-GCM 加密存在本机，密钥材料经 PBKDF2 60 万轮从主密码派生（主密码至少 12 位）；应用向钱包申请访问，钱包自己把请求发给模型厂商，应用只拿到一个会话 token，一键即可撤销。支持 13 家云厂商加本地 Ollama、LM Studio，还能在 Anthropic、OpenAI、Gemini、Cohere 的请求格式之间互转。

命令行 agent（OpenClaw、Claude Code、Hermes）通过本地 bridge 代理接入；bridge 拒绝不带 token 的请求，防止同机其他程序白嫖额度；可按应用设消费上限，并在本地记录每次请求的来源、厂商与状态。项目自己也承认了一件不太宣传的事：当第三方 agent 用 Claude Pro/Max 订阅 token 运行时，bridge 会重命名该 agent 的工具并移动 system prompt，以通过 Anthropic 的一方可疑性检测。GitHub 免费（MichaelLod/byoky）。

「粘贴到设置页的 key，就不再是你能控制的 key」——这句话值得国内每一个做 AI 应用接入的团队抄在墙上。但那个「改名过检测」的默认行为，会让它在任何合规审查里先扣一分：一个安全工具顺手帮你绕过另一家的风控，它的威胁模型就已经不干净了。

ZOLOZ 从 KYC、KYB 延伸到 KYA：给每个进生产系统的智能体发一张密码学数字工牌

Google Mandiant / GTIG研究报告 · LLMjacking🔥🔥🔥

LLMjacking：单日刷掉 10 万美元云账单，有人累计烧到 100 万才被吊销

11 月 2 日，Mandiant 与 Google 威胁情报组（GTIG）发布《The Rise of LLMJacking》，汇总今年多起响应案例：劫持企业 LLM 访问的攻击者，单日就能刷出超过 10 万美元的欺诈云账单；有的组织在被吊销前累计到 100 万美元。与挖矿的区别在于斜率——挖矿慢慢放血，LLMjacking 几小时内就能冲上去。受害者在北美、南美、亚太，含金融、零售、科技与运输。

入口几乎都不是模型本身：被盗或暴露的云身份凭据（服务账号密钥、GitHub PAT），以及对公网开放的 LLM 端点（例如裸奔的 Ollama）。组织 UNC6993 用配置错误的服务账号密钥进入云实例，摸到 LLM API，再架一个假的 LLM 注册页——访客被引到真实服务，并被要求回贴一段含有效 access token 的 JSON，拿到 token 后密码与 MFA 都不再拦路。另一路从公开 GitHub 仓库刮 API Key，每个只用单 token 输出试探，恰好低于基于调用量的告警阈值。路由层也被打了：下游组织拿到预验证的 virtual key 后，利用 LiteLLM 密钥再生端点的 user ID rebind 缺陷（CVE-2026-40217），把普通 virtual key 提成网关的 master admin 凭据。

变现走「LLM Mixers」：把盗来的凭据塞进开源网关与自建中继，计量并隐藏来源。其中 Jet Night 一个路由服务，有行为者 8 小时内打了 50 万次 LLM API 调用，用盗来的第三方 Key 供血，某受害组织因此背上近 100 万美元 token 成本；Jet Night 卖「无限量前沿模型」约 60 美元/月，同类消费级方案要 100–250 美元，GTIG 判断这个价只有盗 Key 才撑得住。还有一路在受害主机上种了基于 Manus agent 框架的容器化后门，让上游模型推理出指令再在本地执行。

最狠的一句是「受害组织从未启用过 LLM 服务」——攻击者用盗来的 Key 替你把 Bedrock 和 Gemini API 打开，账单从几分钟内开始膨胀。「未授权启用云服务」应当被当成关键安全事件处理，这句话建议直接写进云上告警规则。

Sophos勒索团伙 · 智能体滥用🔥🔥🔥

Aur0ra 团伙把 Cursor 的 agent 当雇员用：自己测绘 AD、自己找密码，一路走到域管

11 月 2 日，Sophos 披露其追踪的 GOLD OGRE（即 Aur0ra 勒索团伙）使用 AI agent 在受害网络中移动、收集凭据并爬升到域管理员。8 月底从 Cursor AI 编码助手恢复出的痕迹显示，操作者把 VPN 登录、代理访问、目标与目的交给 agent；agent 随后自己测绘网络与 Active Directory、在网络共享与文档与备份里翻密码、以很少的人工干预横向移动。部分网络拿到域管理权限，其中三个受害者后来出现在 Aur0ra 的数据泄露站。入侵与投勒索仍由人控制。

拿到的操作者指令很具体：一条说 Windows AD 网络需要测试，愿意给 agent 配 SOCKS5 代理和用户账号；一条明确要求「别再暴力破解域管了，换点不吵的方法和向量」；第三条让它去找备份服务器、NAS 与虚拟化系统。操作日志里留下西里尔字母的键盘误触，据此判断操作者为俄语使用者。绕过模型护栏的办法也简单：把入侵描述成「授权红队活动」或「诊断测试」。用过的模型包括 Cursor 的 Composer，以及 Anthropic、xAI、Moonshot 的模型——初期几乎只用 Anthropic，转向实际入侵后引入其他模型。Gambit Security 与 CloudSEK 各自基于同一个暴露的开放目录出了分析，Gambit 提到部署了 Claude 4.5-Sonnet agent 做半自动攻击。

最重要的细节不是「用了 AI」，而是「用红队身份骗过了护栏」。任何靠模型自我判断「这是不是合法安全测试」的机制，在真实攻击者面前只是一道话术题。把授权做成密码学凭据（谁授权、授到哪、到什么时候），而不是做成一句自然语言声明——这是今天唯一真正有效的分界线。

OpenAI / Google / Microsoft / Anthropic行业标准 · IETF AIPREF🔥🔥

四大巨头共推 robots.txt 里的 AI 抓取退出信号：一次写入，多家读取

11 月 1 日，OpenAI、谷歌、微软与 Anthropic 宣布将采用一项新的 AI 数据抓取退出标准。该标准由 Anthropic 标准技术负责人 Kevin Kelley 向 IETF 提出（归属 AIPREF 工作组），直接集成在网站的 robots.txt 里——内容发布方一次写入即可向多家 AI 企业表达「是否可用于模型训练」，不必再逐家配置。Anthropic 已率先采纳，OpenAI 计划未来数月落实，谷歌与微软预计 2027 年支持；Meta 表态支持建立通用信号，但未明确落地计划。微软另提供更细粒度选项：可只拒训练，或单独管控 grounding（把模型指向可信来源以缓解幻觉）；无论怎么设，内容仍会出现在必应搜索结果里。

必须写清边界：这套机制解决的是「表达」，不是「授权」——表达退出偏好不等于与 AI 企业达成许可合同，也不自动产生收益分配；对已经被抓走的存量内容没有追诉力。它也不与已有路线冲突：RSL 允许网站向爬虫收费，Cloudflare 提供 AI 爬虫默认拦截。

治理接口正从「企业间双边规则」迁移到「机器可读的公共协议层」，这一步的意义大于标准本身。但要看清默认值：默认允许、选择拒绝——不表态视为同意。这个默认值决定了它最终保护的是内容方，还是抓取方。

Anthropic护栏分层 · 源码泄露🔥🔥

官网源码露出 Fable 5.5 与 Mythos 5.5：同一套权重，按护栏松紧拆成两个产品

11 月 1 日深夜，anthropic.com/claude/mythos 页面的 HTML 源码里被发现 6 处「Claude Mythos 5.5」（前端显示仍是 9 月发布的 5.1），说明新版本已预埋进生产环境。按目前流传的拆解，Fable 5.5 与 Mythos 5.5 底层是同一套模型、API 定价一致，差别只在护栏：Fable 5.5 带完整安全护栏，作为通用商业旗舰向全球开发者全量开放；Mythos 5.5 解除常规拒答限制，是「特种科研版」，只向受信任的顶尖网络安全团队与科研机构定向开放。规格为 100 万 token 输入上下文、12.8 万 token 最大输出，已同步出现在 MLflow 与 Azure 官方目录。

这个拆法解释了两件此前说不通的事：一是「某未发布内部模型 53 分钟独立攻破 Linux 内核拿到最高权限」，而研究员用现有的 Mythos 5.1 死磕 3 天、烧掉约 2,000 美元都没能复现；二是一篇全篇无人类作者、署名只有 CLAUDE 的数学论文，全程生成约 1,400 万 token。需注明：以上均为源码泄露与第三方爆料，Anthropic 尚未正式发布。

这是「护栏即产品分层」最直白的一次示范：同一个权重，卖出两种风险等级，真正被分级的不是能力，而是「谁能拿到无护栏版本」。国内厂商做「行业版/科研版」时若只改提示词不改交付边界，学到的只是形式。

奇安信行业观点 · 攻防代差🔥🔥

奇安信在乌镇给出两个数字：挖一个高危漏洞从 3–7 天压到分钟级，把漏洞变成武器从数月压到几小时

11 月 2 日乌镇峰会期间，奇安信对《环球时报》给出判断：今年以来 Mythos 这类 AI 挖洞大模型震动业界——挖一个高危漏洞，过去资深工程师要 3 至 7 天，现在压缩到分钟级；把漏洞变成攻击武器，过去要数周数月，现在只要几个小时。结论是网络攻击进入「工业化时代」，而传统「堆设备、拼盒子」的防护存在三重失效：静态化跑不赢动态攻击、人工化扛不住高频攻击、单点化挡不住全域攻击。

给出的应对方向是加快安全升级改造，建设内生安全的一体化纵深防御体系，形成高、中、低三位协同联动的有机整体。同一场大会上，奇安信另有九大领域入选《中国AI赋能的网络安全软件技术发展路线图》，覆盖 Agentic Code Security（Qcode Agents）、Agentic EDR 与 MDR、Autonomous Exposure Management（CTEM）、Agentic NDR（AI 天眼）等类别。

这段最有价值的不是「分钟级」这个数字，而是它承认了一个采购后果：补丁窗口的单位从周变成小时之后，买盒子解决的是覆盖，解决不了速度。速度只能靠「自己先发现」，这也是为什么国内厂商今年集体把漏洞挖掘智能体当成门面产品。

启明星辰 / 券商研报市场数据 · 收入结构🔥🔥

大模型应用防火墙收入同比增长 238.15%：AI 安全的第一批真实收入出现了

11 月 3 日一份 AI 安全行业深度研报给出国内第一个可核对的品类数字：启明星辰 2026 年上半年大模型应用防火墙收入同比增长 238.15%，国内 AI 安全已出现实际收入增长，且传统业务与新业务的景气分化明显。需求沿三阶段加深：办公辅助（内容合规、敏感信息保护）→ 业务协同（跨系统身份认证、权限控制、操作审计）→ 核心生产（高风险操作审批、运行隔离、异常中止与恢复）。

竞争壁垒被归结为三条：数据连接、执行权限、行业交付——模型能提升分析效率，但要看懂「同一次数据库访问在不同账号、设备、业务背景下分别意味着什么」，仍要靠长期部署形成的数据与业务上下文；能隔离主机、撤销凭证、终止进程，才能把「发现」变成「处置」。产业分层也写得很直白：模型原生安全归模型厂商，应用与智能体安全归第三方（跨模型、跨应用统一策略，并与身份、数据治理、SOC 联动），独立评估机构做验证。风险提示同样明确：企业采购不及预期、传统需求承压、模型厂商内置安全功能替代通用检测、防护效果不及预期、盈利与现金流修复不及预期。

238% 要放在基数上看：它证明「大模型应用防火墙」这个品类开始有真实采购，但体量还远不足以对冲传统业务下滑。研报里那句「单纯接入大模型不等于新增收入，客户付费和交付成本变化才是商业化的最终结果」，是今年最该被产品经理记住的一句。

Armadin攻防实测 · 暴露面🔥

88% 的严重漏洞不在厂商公告里：82% 的攻击链不带凭据起步，70% 三步内拿到关键结果

11 月 2 日，由 Mandiant 创始人 Kevin Mandia 创办的攻击性安全公司 Armadin 发布报告：今年对客户真实系统做 AI 驱动攻击测试，88% 的严重与高危发现，靠厂商公告或其他外部来源根本发现不了。客户横跨近十个行业，但公司未披露组织数与发现总数。拆开看：客户自研软件的缺陷占公告覆盖不到的严重发现的 67%、高危的 78%；厂商产品以公告从未描述的方式部署（例如管理控制台直接暴露在公网）占 24% 与 22%；剩下 9% 的严重发现是 Armadin 自己挖的 0-day，其中一个在身份治理平台，厂商近四个月才出公告。

攻击面结构更刺眼：近 70% 的严重与高危发现位于未认证攻击面；有记录的链里 82% 不带凭据起步，其中 56% 全程没出现过密码或密钥；超过 70% 的客户环境中，Armadin 三步以内就拿到关键结果。不带认证起步的链中近一半靠暴露的凭据，其中 71% 属于应用或服务账号而非人，近 90% 无需「提取」即可获得，常在仓库、配置文件、备份、日志、云设置里。修复动作：51% 要改应用代码，43% 改配置权限或策略，32% 轮换暴露凭据；93% 的严重发现不需要第三方动手，修不修全在自己。

AI 在这里的作用不是「发现更多漏洞」，而是「把三步走完」。88% 的真正含义是：漏洞管理的输入（公告）和真实风险（配置 + 自研代码 + 服务账号凭据）几乎是两张不相交的表。按公告打补丁，只能覆盖那 12%。

Cisco TalosAI 恶意软件 · 受害者定价🔥

VOLTA 窃密器让模型给受害者「定价」：按变现容易程度排序，默认用 Claude Opus 4.6

11 月 2 日，Cisco Talos 披露一款 Windows 信息窃取器 VOLTA-AUTODOXER，出自其跟踪「用 AI 的恶意软件」的 CAIRN 研究。前半段很常规：浏览器密码、cookie、支付卡、加密钱包助记词、Microsoft OAuth token、SSH 与云厂商密钥、截图、Discord/Telegram/Steam/Roblox 会话，把本机所有 Wi-Fi 密码明文导出，还自带加密钱包库爆破。后半段才是新东西：它组一个「证据包」——地理位置与家庭住址、雇主与雇主域名、推断出生年、卡号后四位、Slack 工作区、文档作者元数据、iPhone 备份痕迹、Roblox 账号估值；再用窃来的会话去 Gmail 搜购物收据核对住址、拉 UberEats 与 DoorDash 订单史、用 Discord token 补全账号。

然后打包成 JSON POST 给 OpenRouter，system prompt 让模型扮演取证情报分析师，按「变现容易程度」给资产排序并打低/中/高，评判受害者的安全习惯与密码卫生，还要在姓名、住址、学校与所选密码之间找关联。默认模型是 Claude Opus 4.6；一旦检测到拒答措辞就转 Moonshot 的 Kimi K2，再转 Gemini 2.5 Flash。结果落成 Identity_Report.txt 与 AI_Analysis.txt，一起打进 volta_dox.zip 外传。运行后自删，所有通信端点都属第三方，没有攻击者自有基础设施可打。配置写在模板六个槽位里、编译时填入——典型的「builder 模式」：作者卖访问权，买家填值，作者为其编译定制二进制。

这是「以模制模」的镜像。我们讨论用 AI 检测 AI 攻击时，攻击者已经用 AI 做完了「这份数据值多少钱」的判断——而那一步过去是最费人的。Talos 的总结值得抄进每一份威胁模型：找出最需要人持续注意的那一步，把它换成一次模型调用。

🧭趋势判断 · 精简版

一、攻击者已经不需要漏洞，需要的是「一个能发请求的账号」

今天三条最硬的新闻讲的是同一件事：LLMjacking 打的是账单而不是系统，入口是服务账号密钥和一个裸奔的 Ollama；VOLTA 打的是「这个人的价格」，靠的是浏览器里存着的会话与 OAuth token；Aur0ra 打的是 EDR 的信任判断，靠的是一句「这是授权红队测试」。三条链里，只有 Armadin 那 9% 涉及真正的 0-day，而它自己也承认 82% 的链不带凭据起步。攻击面的重心已经从「软件有没有洞」挪到「凭据躺在哪里、谁能替它说话」。

二、授权正在取代检测，成为唯一能写进合同的那一层

Aur0ra 用「红队」两个字骗过护栏，直接说明护栏的判定依据如果是自然语言，它就只是话术题。对照今天的产品侧：Salesforce 把评估失败接到 kill switch，蚂蚁把授权额度锁进智能合约并上链存证，天泽把每个动作绑到一次审批上，Byoky 让应用只拿会话 token 而密钥留在钱包里——四条动作的共同点是把「谁允许的」变成可验证的凭据，而不是可解释的声明。这也是为什么「智能体身份证」会成为接下来一年最拥挤的赛道。

三、护栏开始被当成产品分层的维度来卖

Anthropic 把同一套权重拆成带护栏的 Fable 5.5 与解限的 Mythos 5.5，定价一致、差别只在拒答边界与交付对象。这是护栏第一次被明确标价——不是按能力收费，而是按「你敢不敢解除限制」收费。国内的对应版本是「行业版/科研版」，但目前多数只改提示词、不改交付边界，学到的只是形式。真正的分层必须包含三件事：谁能拿到、拿到后能做什么、出事谁负责。

四、治理接口向协议层迁移，但默认值决定它保护谁

robots.txt 的统一退出信号是好事：把「逐家谈判」变成「一次表达」，降低了中小站点的合规成本。但它默认允许、选择拒绝，不产生合同、不产生分成、不追诉存量——它降低的是表达门槛，不是议价能力。同一周的另一面是 RSL 允许收费、Cloudflare 默认拦截，三条路线并存说明内容方还没找到统一的杠杆。对做 AI 数据合规的厂商，机会不在写规则，而在做「谁在什么时候用了我的什么」的可核对账本。

五、修复的瓶颈不在技术，在「这活归谁」

Armadin 的 93% 是今天最值得抄的一个数字：绝大多数严重问题不需要第三方动手，修不修完全取决于自己。但同一份报告里，51% 要改代码、43% 要改配置、32% 要轮换凭据——三个动作分属三个部门，没有一个部门能独立完成。这解释了为什么「暴露面管理」在国内一直卖不动：它不是产品缺口，是责任缺口。谁能把「发现→派单→验证→关闭」的归属关系做成产品的一部分，谁才真正卖得出去。
