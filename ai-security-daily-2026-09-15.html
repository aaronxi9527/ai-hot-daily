🧭 AI 总览

今日主线是 「治理框架落地，产品同步卡位」。国内侧，网安周开幕式一天之内连出三件硬货：《人工智能安全治理框架 3.0》正式发布并首次配套《智能体风险管理框架》，把「智能体安全」写进国家层面的风险分类；CCIA 首批《人工智能防火墙产品测评证书》发出，全国只有四张，天融信、奇安信、绿盟、山石各拿一张，AI 防火墙这个品类算是有标准可依了；产品端也没闲着，蚂蚁在网安周首日放出内生式安全护栏 SingProbe，思路很不一样——不挂外置护栏模型，而是把检测融进解码过程，额外开销低于 0.5%，还同步开源了流式评测基准 SingStreamBench；天融信今天 15:15 发《智能体全域安全防护框架 1.0》，中国移动的 AI 代码审计引擎把误报率压到 15% 以内，江苏移动的「金陵智剑」把漏挖效率拉高 3-5 倍。

国际侧的看点更集中在「谁在定义边界」。微软抛出 37 页《人文主义人工智能行为准则》草案，明说愿意为安全牺牲通用性与能力，直接把「人比 AI 更重要」写进文档第一句，当天美股网安板块逆势大涨，CrowdStrike、Zscaler 各涨 14%。Google 则把智能体沙箱体系推上 GA，用 VPC 服务边界、客户自管密钥和 100ms 挂起 / 280ms 恢复的可持久化沙箱，把「执行环境」这一层收进可控范围。反面教材同样醒目：一次未被审查的 MCP 配置改动（Miasma 行动）让攻击者拿到 73 个 GitHub 仓库的 OS 级权限，其中一个属于微软 Azure，根因是审批绑定在服务器名字而非内容上——20 万+ 脆弱实例、1.5 亿次下载。Anthropic 一边公开智能体「爆炸半径」遏制工程，一边由 Amodei 喊出减速，但 IBM 提醒得很实在：开源模型不会一起踩刹车。

一句话：标准在补、产品在跑、攻击者在前面。

Google Cloud 跨领域：执行环境隔离 🔥🔥🔥

Gemini Enterprise Agent Platform 沙箱体系 GA，GKE Agent Sandbox 同步转正

Google 于 9 月 9 日把 Computer Use 与 Shell 两类沙箱正式推向 GA，并补齐了决定「能不能进生产」的四项控制：VPC Service Controls / Private Service Connect 私有连通、客户自管加密密钥（CMEK）、以及暂停-恢复时保留文件系统状态与连接身份。同期 GKE Agent Sandbox 转为 GA、Cloud Run Sandboxes 进入预览，官方给出「默认拒绝（default-deny）+ gVisor 隔离」的硬指标：单集群 <1 秒起沙箱、峰值 300 沙箱/秒，Pod Snapshots 可将空闲会话挂起约 100ms、恢复约 280ms，空闲算力开销最高降 90%。需要注意的两点：Shell 沙箱以非特权 appuser 运行且出网默认关闭，但官方文档未宣称 microVM 级隔离；VPC 服务边界一旦启用，Gemini Notebook Enterprise 将无法摄取任意网页 URL。

TeamPCP / UNC6780 安全事件MCP 供应链安全 🔥🔥🔥

「Miasma」攻击：一次未被审查的 MCP 配置改动，拿到 73 个 GitHub 仓库的 OS 级权限

9 月 14 日披露的 Miasma 行动（归因 TeamPCP / UNC6780）把 MCP 工具投毒从 PoC 推到了实战：攻击者在 73 个 GitHub 仓库中植入恶意 MCP 配置文件，其中包括微软 Azure 的一个仓库，借此以开发者身份执行任意命令。根因是多个主流 IDE/编码助手（Cursor、Claude Code、Gemini CLI、GitHub Copilot、Amazon Q）把「是否信任此 MCP 服务器」的确认绑定在服务器名称而非内容上——项目里的 .mcp.json 一旦批准，之后任何改动（包括被换成恶意命令）都会自动以开发者 OS 权限执行，不再提示、不进沙箱。影响面：受影响 MCP SDK 与客户端存在20 万+ 脆弱实例、1.5 亿次库下载；OWASP 已将工具投毒列为 MCP Top 10 第 3 位。缓解建议是把 MCP 配置变更当作代码评审事件、对工具定义做哈希/版本锁定、按工具最小授权、维护 MCP 服务器白名单并对智能体执行做沙箱化。
