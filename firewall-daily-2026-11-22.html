其他 Palo Alto 11-20 🔥 重点

PAN-OS 曝双 9.2 分 NGINX HTTP/2 漏洞：CVE-2026-123633 与 CVE-2026-123007，开启 HTTP/2 即暴露

Palo Alto 于 11-20 发布安全公告，披露 PAN-OS 与 Panorama 内置 NGINX 的两个严重漏洞：CVE-2026-123633（HTTP/2 代理 use-after-free，CWE-416）与 CVE-2026-123007（HTTP/2 流控整数下溢，CWE-191），CVSS-B 均为 9.2，未认证远程攻击者可打崩 worker 进程或以 root 执行任意代码。

受影响版本：12.2.4 及更早、12.1.7 及更早、11.2.10 及更早；仅在启用 HTTP/2 时受影响，未启用则不受影响，关闭 HTTP/2 可作临时缓解。修复版本 12.2.4-h3 / 12.1.10-h6（或 12.1.7-h15）/ 11.2.16-h3。厂商称暂未发现恶意利用，但 GitHub 上已有 PoC。值得注意的是这已是十一月内 Palo Alto 因「管理面跑通用 Web 组件」引发的第三起高危披露（前有 PHP2Shell 与 Panorama CVE-2026-0330）。

其他 兆勤 Zyxel 11-15

兆勤 USG FLEX H 系列防火墙原生整合 Bitdefender GravityZone，自 uOS 1.40 固件起提供

兆勤科技宣布 USG FLEX H 系列防火墙可原生整合 Bitdefender GravityZone，网管人员在单一界面即可查看端点授权、操作系统版本与端点安全状态，减少防火墙与终端之间的安全孤岛。该能力自 uOS 1.40 固件起提供。

2027 年计划新增端点风险评分、预设防御行动与威胁情资共享，但自动隔离机制尚未公布。需注意分工边界：端点防护授权仍由 Bitdefender 管理，扫描与运算主要在端点侧完成，防火墙并不执行完整防毒扫描——这一点与「防火墙内置 AV 引擎」是两条不同路线，前者是把墙做成端点数据的汇聚面板，后者是把检测算力压在墙里。
