为什么智能体会吃掉整个赛道？因为 5 个月里发生了三次"性质变化"：

2026-06-16
第一次：AI 从"被攻击对象"变成"攻击执行者"
全球首例 LLM Agent 自主网络攻击被确认 —— 60 分钟内完成从入侵到数据窃取的全流程。 同周 Miasma 供应链蠕虫攻陷 73 个微软 GitHub 仓库、304+ 组件受影响。 这两条同时说明：防御对象不再是"模型会不会说错话"，而是"智能体会不会自己动手"。
2026-07-07
第二次：全自主勒索软件出现，同一天四件大事
JADEPUFFER（全球首例全自主 AI Agent 勒索软件）曝光； OWASP 发布 Agentic AI Top 10； 美国白宫首次直接干预 OpenAI 新模型发布节奏； 中国 AIGC 双新规（网络安全标识 + 拟人化互动服务管理）同日实施。 攻防两侧与监管侧在同一天同时表态 —— 这是本区间信息密度最高的一天。
2026-09-05 / 10-07
第三次：智能体身份与权限成为独立产品品类
AppViewX 上新智能体身份安全能力（端点发现影子智能体 + MCP 网关 + 一键 Kill Switch）； Okta、SailPoint 相继补齐智能体身份治理。 「智能体是一个需要独立账号、独立权限、独立审计的主体」这个认知正式产品化。
第二个结构性判断：防火墙赛道的主线是"性能与架构"（ASIC、Tbps、时延）， AI 安全赛道的主线是"身份与权限"。因为智能体的风险不在网络层，在它能做什么。 这意味着做 AI 安全的厂商，竞争壁垒不在硬件，在能不能管住一个会自己决策的主体。

10判断

七条，按可执行性排序
1
MCP 管控是当前最明确的产品空白。国内 10 家全部为 ○，国际只有 Netskope 与 AppViewX 在做， 而 MCP 相关条目已有 233 条。强证据 谁先做出 MCP 流量管控产品，谁就定义了品类。
2
《智能体应用安全基本要求》立项是 12–18 个月后的采购刚需。强制性国标落地路径与等保一致。 强证据 现在参与编制 = 未来标准条款里带自己的产品定义。
3
认证的价值已被三次验证。天融信增强级证书、绿盟 L2 001 号、腾讯云信通院可信评估 —— 三家都靠认证拿到可写进标书的资格项。强证据
4
国内厂商缺少可量化指标。华为有 95%、CrowdStrike 有 200+ 种注入手法、群星有 95% 降噪， 国内多数产品只有定性描述。中证据 指标是可被竞品攻击的，但没有指标就无法被比较。
5
防护点必须从"入口"移到"运行时"。攻击面已完成四次迁移（模型→提示词→MCP→身份）， 只做网关覆盖不到后两波。趋势确定
6
独立提示词注入厂商窗口正在关闭。Lakera 被 Check Point 整合、Cloudflare 内置、华为 95% 打包进防火墙。 窗口收窄 这个功能将变成平台标配而非独立 SKU。
7
国内产品哲学与国际分岔，短期不会收敛。国内走"网关+评估+认证"（防火墙思路延伸）， 国际走"身份+可观测+自治响应"（SOC 思路延伸）。中证据 出口与国际竞争时这是硬伤，国内市场反而更吃"认证"这一套。
如果只做一件事：把 MCP 流量管控 列成独立产品立项。 理由是三重的 —— 国内零覆盖（竞争空白）、有 233 条情报支撑需求真实存在、且与《生成式人工智能系统互操作安全规范》 这份正在征求意见的国标直接对应。这是两条报告里唯一一个"竞争空白 + 标准将立 + 需求已验证"三重叠加的位置。
