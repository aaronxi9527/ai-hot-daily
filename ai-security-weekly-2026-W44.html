攻击能力跃升
三条独立证据		 ①Anthropic 未发布模型在只有初始提示下把 Chrome 四个漏洞串成可用利用链（V8 内存破坏 → 逃沙箱 → …），开个网页就弹计算器；②开源权重 GLM 5.3 用 patch gap 自主串出 Firefox 6 个版本的完整利用链，每次约 1,000 美元，最快 12 小时；③VAPOR PANDA 的 ARTEX 控制器 11 天打了 200+ 组织，单次入侵消耗 14 亿 input token。
这一周最值得记住的一个数字是 45 分钟。PHP 的两个 RCE 从补丁发布到数万次利用，只隔了 45 分钟。而防火墙、网关这类设备的固件更新周期通常以周、以月计。「AI 挖洞、AI 打洞」把漏洞的窗口期从周压到小时，而设备侧的修复能力还停在周——这个错配本身就是产品机会：虚拟补丁、热补丁、策略级缓解，正在从「加分项」变成「必需品」。

04对 NF 的判断

每条标注证据强度：强 多源互证或官方一手 · 中 单一来源但口径清晰 · 弱 推断

1
「AI 安全网关 / 大模型卫士」已经被写进国家级规划的功能定义里，这是产品目录级的信号，不是一个技术方向。
《信息化「十五五」规划》10-29 发布版把网络安全单列成章，并直接规定了三类产品的功能边界：AI 安全网关（位于 AI 应用与模型、MCP 工具及业务系统之间，统一接入 + 成本治理 + 数据安全 + 全链路可观测）、大模型卫士（安全网关 + 风险 AI 鉴定 + 监测审计平台，检测—管控—审计—溯源闭环）、智能体安全管理。规划写功能边界的下一步就是采购目录写品目，再下一步就是招标文件写参数。这三类产品里，「网关」这一类天然落在网络设备厂商的能力范围上——NF 现在不做，两年后就是在别人的品目里做配套。
强 国家级规划原文 + 同期天融信/华为/奇安信的产品命名高度重合，说明行业已按此对齐
2
MCP 工具调用是目前最薄的一环，而它恰好是防火墙能看见的那一环。
本期 18 个 MCP 安全标签里有两条硬证据：①一天 9 个 CVE 集中在 MCP 工具服务器把参数直接拼进 shell，任何被提示注入的 agent 都能执行任意命令；②AWS Strands 把「脱敏开关」做成模型入参，一句提示就能让环境变量明文返回。这两类问题的共同点是：攻击流量在网络上跑，但没有任何网络设备在检查它。Fortinet 已经给了答案——Inline AI Security Service 在 FortiGate 上检查 MCP 工具清单/调用/响应（双向），并做了 35 类 PII 识别。NF 有天然的位置优势（流量必经），缺的是 MCP 协议解析 + 工具调用语义检测这两块能力。
强 9 个 CVE 同日集中披露 + AWS 官方披露 + Fortinet 已上线同类能力，三源互证且互不依赖
3
「AI 防火墙」已经是带评分表的独立品类，不在名单上就等于在技术分上先输一截。
两条线同时在收口：T/CCIA 006-2026《人工智能防火墙产品测评》首批名单（天融信三季报确认首批取证、华为 USG6855G 在列），同期 IDC 首份《中国大模型应用防火墙技术评估，2026》给出技术创新力五星（华为 USG6000G）。加上《十五五规划》把「大模型卫士」写成产品定义，这个品类的评价体系已经齐了：有测评标准、有第三方评估、有政策定义。防火墙那份周报里已经指出绿盟在本期两份名单中均未见公开卡位——本条是从 AI 安全视角再次确认同一件事。
中 名单非全量公开，不能排除未披露；但两家竞品的卡位是公开且可核的
4
「默认拒绝出站」正在成为智能体场景的合规基线，这是 NF 可以直接兑现成功能的一条要求。
印度 CERT-In CIAD-2026-0049 明确要求智能体沙箱隔离 + 网络层默认拒绝出站，并特意加了一句「而非仅靠提示词约束」；国内信通院同期提出「涉及资金、重要数据及生产设备的操作应设置人工确认和外部校验」；OpenAI 的红队结果则从反面证明——它们让 agent 复用防火墙已放行的连接去访问被封的 metrics 服务，说明「已放行连接」是逃逸的主要通道。这三条拼起来是一个具体功能：面向 AI 工作负载的出站白名单 + 连接复用检测 + 高风险动作的强制二次确认。不需要等标准落地，现在就能做，而且是投标文件里可以正面写的差异点。
强 境外监管通告 + 国内信通院观点 + OpenAI 红队实证，三种性质的信源指向同一结论
5
45 分钟的漏洞窗口期，会把「虚拟补丁 / 热补丁」从加分项变成必需品，这块能力要提前备好。
PHP 双 RCE 从补丁发布到数万次利用只隔 45 分钟（Cloudflare 在补丁日 03:02 UTC 就推了 WAF 规则，仍没拦住）；GLM 5.3 用 patch gap 打穿 Firefox 六个版本，每次成本约 1,000 美元；天融信把「前沿虚拟补丁智能体」写进 Q3 产品发布，方向已经有人验证。设备侧固件更新以周计，攻击侧以小时计——这个错配只能靠策略级缓解来补。NF 需要的是「漏洞公告发布后 4 小时内可下发的策略模板」，而不是等下一个固件版本。
中 时间线数据硬，但「4 小时」的能力目标属推断，参照的是竞品已发布产品形态
如果本周只能做一件事：把「AI 安全网关」做成 NF 上的一个可交付形态，而不是一条独立产品线。理由有三条，都能在本期找到硬证据——①规划已经写了这个品类的功能边界，早晚要进采购目录（判断 1）；②它的核心检测点在流量上，NF 有位置优势，而竞品已经在 FortiGate 上做了同样的事（判断 2）；③它天然带「出站管控」能力，正好对上「默认拒绝出站」这条正在形成的合规基线（判断 4）。三件事指向同一个动作：在防火墙上长出 AI 检测面，而不是在防火墙旁边再摆一台盒子。
